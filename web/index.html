import requests

API_URL = "http://127.0.0.1:8080/api/v2"
HEADERS = {"X-API-Key": "digitdns_live_your_key_here"}

# Create subscriber account on plan purchase
def create_smartdns_user(username, days=30):
    res = requests.post(f"{API_URL}/clients", headers=HEADERS, json={
        "display_name": username,
        "validity_days": days
    })
    res.raise_for_status()          # 201 with the client object
    return res.json()["token"]

});

  if (status === 201) {
    ctx.reply(`🎉 SmartDNS Created!\n🔗 Registration token: ${data.token}`);
  }
}

Proxy Leak Protection

                

                  Proxied names never advertise QUIC or the origin's real addresses.
                  HTTPS and SVCB answers are withheld so clients use the proxied A/AAAA records over TCP.
                

              

            

            

              ACTIVE
              
            

          


          

            

              
HTTPS / SVCB

              
withheld

            

            

              
h3 / QUIC

              
not advertised

            

            

              
IPv4 / IPv6 hint

              
removed

            

          


          

            Live for every Proxy domain; direct names keep normal records.
          

          

            Protection is off. Proxied names may advertise QUIC and real IPv4/IPv6 hints, allowing clients to bypass the relay.
          

          

            Recommended: keep this enabled. Turning it off lets proxied names advertise QUIC and origin IPv4/IPv6 hints,
            which can bypass the relay. Only change this if you know what you are doing.
          

        


        
        

          

            

              

                
              

              

                
Proxy IPv6

                

                  Publish this server's IPv6 for proxied domains. Off keeps clients on the IPv4 relay and blocks every IPv6 hint.
                

              

            

            

              OFF
              
            

          


          

            
            
            

              The SNI proxy must be reachable on this address. AAAA is withheld when it is empty.
            

            

              IPv6 is off: proxied AAAA is withheld and HTTPS/SVCB hints stay blocked even if proxy leak protection is disabled. Agents switch to IPv4-only on their next heartbeat.
            

            

              IPv6 is on: proxied AAAA uses this address and agents re-enable IPv6 on their next heartbeat. HTTPS/SVCB remains governed by Proxy Leak Protection.
            

          


          

            
            
          

        

        


        
        

          

            

              

                
              

              

                
DNSSEC Validation

                

                  Validate the DS/DNSKEY chain, answer signatures and NSEC/NSEC3 denial proofs inside this hub.
                  Validated answers carry AD; bogus answers return SERVFAIL.
                

              

            

            

              OFF
              
            

          


          

            
            
            

              Empty uses the built-in IANA root anchors. Custom anchors must name the root
              (.) and are validated before saving.
            

            
Built-in IANA root anchors

            

          


          

            
            
          


          

            Saved settings differ from the running engine. Restart DigitDNS to apply the new DNSSEC policy.
          

          
Changes are startup-only and take effect after a restart.

        

        


        
        

          

            

              
            

            

              
Traffic History

              
90-day aggregates only — no raw query log is written to disk.

            

          


          

            
            
            
            
          


          

          

            Retention, top-N limits and the opt-out list apply after a daemon restart. Client anonymization affects new aggregates;
            existing rows in stats.db keep the identifiers they were written with.
            Disabling history stops new writes but leaves the existing database intact.
