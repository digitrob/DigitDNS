Quick Integration Code Snippets 

# 1. Check Engine Health
curl -X GET "http://127.0.0.1:8080/api/v1/status" \
  -H "X-API-Key: digitdns_live_your_key_here"

# 2. Create User Account (30 Days)
curl -X POST "http://127.0.0.1:8080/api/v1/clients" \
  -H "X-API-Key: digitdns_live_your_key_here" \
  -H "Content-Type: application/json" \
  -d '{"name":"Gamer-VIP","expires_days":30}'
import requests

API_URL = "http://127.0.0.1:8080/api/v1"
HEADERS = {"X-API-Key": "digitdns_live_your_key_here"}

# Create subscriber account on plan purchase
def create_smartdns_user(username, days=30):
    res = requests.post(f"{API_URL}/clients", headers=HEADERS, json={
        "name": username,
        "expires_days": days
    }).json()
    if res.get("success"):
        return res["data"]["register_url"]
    return None
const axios = require('axios');

const client = axios.create({
  baseURL: 'http://127.0.0.1:8080/api/v1',
  headers: { 'X-API-Key': 'digitdns_live_your_key_here' }
});

// Example Telegram Bot Handler
async function onBuySubscription(ctx, username) {
  const { data } = await client.post('/clients', { name: username, expires_days: 30 });
  if (data.success) {
    ctx.reply(`🎉 SmartDNS Created!\n🔗 Register IP: ${data.data.register_url}`);
  }
}

Subscription Portal

The public pages your subscribers open. Links are built from …

A local file is read from the server's disk and inlined; a URL is loaded by the subscriber's browser. Inline and local CSS are sanitised (no @import or external url()).

Issue a certificate for the subscription domain above. Empty the domain field and click to go back to the panel's name.

A port other than the panel's opens a dedicated public listener for the subscriber pages. Open it in the host firewall too — on Ubuntu that is ufw allow <port>/tcp — or the links in this card will time out from outside even though the daemon is serving them.

How to Connect Client Devices

Connect your Gaming PC, PlayStation, Xbox, Android, iOS, or Router in seconds without installing any client software.

Windows 10 / 11 (Gaming PC)

  1. Open Settings > Network & Internet > Wi-Fi / Ethernet.
  2. Click Edit DNS assignment > Select Manual.
  3. Turn on IPv4 and enter your Server IP:

PlayStation 5 / Xbox

  1. Go to Settings > Network > Set Up Internet Connection.
  2. Select Wi-Fi/LAN > Advanced Settings > DNS: Manual.
  3. Set Primary DNS to your Server IP:
Loading IP...

Android Private DNS (DoT)

  1. Go to Settings > Network & Internet > Private DNS.
  2. Select Private DNS provider hostname and enter:
dns.yourdomain.com

Browser Secure DNS (DoH)

  1. In Browser: Settings > Privacy & Security > Use secure DNS.
  2. Choose Custom and paste your DoH URL:
https://your-server-domain:8443/dns-query
